1
AI opens first — greets with context from last scan. User never lands on a blank screen. No menu to navigate.
2
Natural language input — "scan it again", "explain in Swahili". No forms, no target fields to fill.
3
Result card inline — grade, severity pills, top CVEs, action buttons all inside the conversation. Scan history is never more than a chat bubble away.
4
Severity color language from security conventions — red/orange/yellow. Familiar to anyone who's seen a security tool, but in a minimal card instead of a sprawling table.
5
Bilingual inline — AI responds in the language the user typed. No setting to toggle, no page reload.
6
Header: only two controls — History (past scans drawer) and Settings (API key, language). Nothing else.
